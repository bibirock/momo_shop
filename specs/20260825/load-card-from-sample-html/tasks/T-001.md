## 任務描述

建立 demo-food canonical config 的 Zustand persisted store、schema 驗證與 default fallback，讓 Showroom 與 Embed 讀寫同一份資料；Embed 不直接操作 localStorage API。

包含檔案：

- `components/product-card/product-card-store.ts` — persisted store、儲存動作與 hydration-safe 讀取介面。
- `components/product-card/product-card.validation.ts` — persisted payload 驗證與 fallback。
- `components/product-card/product-card.types.ts` — store snapshot 與公開型別。
